# Carapace Corruption

This repository contains a minimal Factorio 2.0 mod scaffold for a custom fluid, incubator prototype, and biter unit.

## Included

- `info.json` with the mod metadata
- `data.lua` with prototypes for Cyber-Slurry and the Incubator Pen
- `control.lua` with event registration and periodic checks

## Publish to GitHub

```bash
git init
git add .
git commit -m "Initial mod scaffold"
git branch -M main
git remote add origin https://github.com/your-user/carapace-corruption.git
git push -u origin main
```
